# VERIFY

Папка для ручной проверки перед установкой на рабочий стол.

Что здесь искать:
- `main.ru` - текущая точка запуска приложения
- `app/` - восстановленная структура логики приложения

Что проверить:
1. Открыть `main.ru` или запустить `run.bat`.
2. Убедиться, что приложение стартует.
3. Проверить, что ветка `codex/fix-launch-structure` доступна в GitHub.

Следующий шаг после вашей проверки:
- подготовить desktop-install и собрать `.exe` для установки на рабочий стол.
